# Диагностика DNS

Чек-лист для случая, когда интернет по IP доступен, но сайты по именам не открываются.

## Проверки

```cmd
ipconfig /all
nslookup google.com
nslookup google.com 8.8.8.8
ipconfig /flushdns
```

`ipconfig /all` показывает назначенный DNS. Адрес шлюза может быть DNS proxy/forwarder, а не внешним DNS-сервером.

`nslookup` проверяет DNS-сервер по умолчанию. `Request timed out` может означать недоступный сервер, неработающий proxy, проблему маршрута, firewall или VPN.

Сравнение с публичным DNS допустимо только как диагностическая проверка, если это разрешено политикой организации. Работающий публичный DNS не означает, что его можно назначить постоянно.

`ipconfig /flushdns` очищает кэш DNS-клиента Windows. Команда не чинит DNS-сервер, DHCP, proxy, firewall или маршрут.

## Эскалация

Передайте заявку администратору, если DNS не отвечает нескольким пользователям, нужно менять DHCP/firewall/DNS-зоны или публичный DNS работает, а корпоративный нет.
