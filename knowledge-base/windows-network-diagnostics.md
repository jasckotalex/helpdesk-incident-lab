# Диагностика сети Windows

Краткий чек-лист первой линии для учебной диагностики сетевого подключения.

## Основные команды

```cmd
ipconfig /all
ping <адрес_шлюза>
ping 8.8.8.8
tracert 8.8.8.8
route print
```

`ipconfig /all` показывает адаптеры, IPv4-адрес, шлюз и DNS. Адрес `169.254.x.x` обычно указывает на проблему получения адреса через DHCP.

`ping` до шлюза проверяет локальную связь, а `ping 8.8.8.8` — путь до внешнего IP по ICMP. Тайм-аут не всегда означает отсутствие доступа: ICMP может блокироваться.

`tracert` помогает увидеть, где прекращаются ответы. `route print` показывает маршруты на клиенте, но не таблицу маршрутизации удалённого маршрутизатора.

## Следующие действия

- шлюз недоступен — проверить интерфейс, кабель или Wi-Fi;
- шлюз доступен, внешний IP недоступен — проверить VPN, WAN, default route, NAT и firewall;
- внешний IP доступен, сайты по именам нет — перейти к DNS-чек-листу;
- проблема у нескольких пользователей — эскалировать как сетевой инцидент.
